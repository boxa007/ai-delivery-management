# Урок 6 - Роздатка: збери свого Delivery-агента

Усе, щоб зібрати робочого агента, який слухає запис дзвінка і сам ставить задачі виконавцям у трекері. Імпортуєш workflow → підставляєш 3 ключі → міняєш список команди на своїх людей → агент працює.

## Швидкий старт (за 7 кроків)

1. **n8n:** імпортуй `workflow-meeting-notes-clickup.json` (Workflows → Import from File).
2. **DeepInfra:** зареєструйся на deepinfra.com → API keys → встав токен у ноду **Transcribe (DeepInfra Whisper)**, Header Auth.
3. **OpenAI:** встав ключ у sub-ноду **OpenAI Chat Model** (НЕ в chain - помилка #1).
4. **ClickUp:** Settings → Apps → API Token → встав у ноду ClickUp. Там же візьми `list_id` свого списку.
5. **Команда:** відкрий ноду **Set: Team & Glossary** → заміни приклад на СВОЇХ людей із їхніми `user_id` (як їх дістати - у чек-листі, Етап 3).
6. **Запусти:** відкрий форму (Form Trigger дає посилання) → завантаж запис дзвінка → Submit.
7. **Перевір чесність:** у дзвінку має бути фраза-ідея без згоди («колись би нам...») - агент НЕ має робити з неї задачу.

> Детально кожен крок + помилки - у **CHECKLIST-build-agent.md**.

## Стек (нагадування з лекції)

- **n8n** - оркестратор (зʼєднує все, працює 24/7)
- **DeepInfra Whisper large-v3** - розпізнавання (дешевше за OpenAI API, той самий `large-v3`)
- **Basic LLM Chain + gpt-4o-mini** - мозок-екстрактор (дешево, для екстракції з готового тексту досить)
- **Structured Output Parser** - форсує чистий JSON (action_points / decisions / risks)
- **IF-нода** - гейт: `confidence: high` летить у трекер, решта на підтвердження PM
- **ClickUp / Jira** - вихід (міняється ОДНА нода)

**Головне правило:** рушій розпізнавання і трекер - змінні деталі на краях. Мозок посередині не змінюється. Хочеш ElevenLabs замість Whisper - міняєш одну ноду. Хочеш Jira замість ClickUp - міняєш одну ноду.

**Друге правило:** ключ OpenAI живе на sub-ноді **МОДЕЛІ**, не на chain. 90% «чому не працює» - шукали credential не там.

## Чому це АГЕНТ, а не транскрибація (нагадування суті уроку)

- **Транскрибація** віддає вам 40 сторінок тексту. Читати, виділяти дії, призначати виконавців і ставити задачі - ваша робота.
- **Агент** віддає 5 задач у трекері з виконавцями, дедлайнами і цитатою з дзвінка в описі. Ваша робота - переглянути і підтвердити.

Питання-лакмус: після роботи інструмента вам ще треба щось робити руками? Якщо так - це транскрибація, навіть якщо на коробці написано «AI».

## Whisper чи ElevenLabs - що брати саме вам

| Ваша ситуація | Рушій |
|---|---|
| Чиста українська / англійська, добрий мікрофон | **Whisper на DeepInfra** (дешевше) |
| Суржик, кілька людей у кімнаті, треба розділення спікерів | **ElevenLabs Scribe** (стабільніше тримає змішане мовлення) |
| NDA-проєкт, дані не мають виходити з контуру | **self-host Whisper** (GPU + DevOps, реальні гроші) |

> Це оцінка з моїх прогонів на моїх файлах, не лабораторний бенчмарк. Візьми `sample-data/` і прожени обидва - послухай своїми вухами. У workflow нода транскрибації одна, поміняти рушій = поміняти URL і body в ній.

## ⚠️ Важливо: приватність (з лекції, блок 6)

Запис дзвінка = персональні дані. Правила:

> **Згода на запис** (вмикайте вбудоване сповіщення Zoom/Meet) · **перевірте договір із клієнтом** щодо передачі даних третім сторонам · **NDA-проєкт → або self-host, або не автоматизуємо.**

Спитати можна завжди, повернути назад передані дані - ні. Перевірте договір ПЕРЕД першим прогоном реального клієнтського дзвінка, а не після.

## Домашка-хакатон

Вибери **1 трек** (складність вказана - бери по силах):

| Трек | Що робиш | Складність |
|---|---|---|
| **A · Нотатки після дзвінка** | запис → action points → задачі у твій трекер | 🟢 easy - готовий workflow тут |
| **B · Статус-апдейт клієнту** | дані проєкту за тиждень → звіт | 🟢 easy - готовий скіл тут |
| **C · Генерація SoW** | onboarding-дзвінок → чернетка SoW | 🟡 medium - свій промпт і структура |
| **D · Risk tracking** | ризики з усіх дзвінків → накопичувальна таблиця + алерти | 🔴 hard - стан між прогонами |

Далі, незалежно від треку:
1. Візьми **реальні дані**: 2-3 справжні записи твоїх дзвінків (можна обезличені) або справжній проєкт.
2. Збери під свій кейс: імпорт workflow + свій список команди + свій словник проєкту.
3. Прожени **2-3 реальні дзвінки** → перевір, що задачі адекватні, виконавці правильні, а сміття НЕ стало задачами.
4. **На наступній зустрічі - демо + зворотний звʼязок.**

**Критерії оцінки:** працює (0-3) · чистота, сміття не стало задачами (0-3) · цитата з дзвінка на кожну задачу (0-2) · виконавці призначені правильно (0-1) · реальні дані (0-1).

**Прохідний:** працює + не робить сміттєвих задач + цитує дзвінок.

> Застряг - пиши, розберемо на зустрічі. Мета не ідеальний агент, а РОБОЧИЙ під твій справжній процес.
